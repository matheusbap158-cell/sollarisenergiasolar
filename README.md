# Sollaris Energia Solar: landing page

Landing page em arquivo único (`index.html`), com a logo em `assets/`. Energia solar em Varginha/MG. Status: demo, não publicada.

## Como visualizar
Abra o `index.html` com duplo clique (caminhos relativos, sem servidor). Para ver as pendências marcadas, adicione `?revisao` ao endereço.

## Estrutura
- `index.html`: hero com ilustração própria (sol, colinas e painel solar em CSS), faixa de provas, por que a Sollaris, como funciona, avaliações reais do Google com a resposta da empresa, banda de WhatsApp, formulário de orçamento (3 perguntas, abre o WhatsApp), onde estamos com mapa.
- `assets/logo.png`: logo recortada, fundo transparente. `assets/logo-claro.png`: versão branca para o rodapé escuro.
- `Copy.txt`: texto da página. `design-system-sollaris.html`: design system.
- `Logo/`, `Info para copy/` e link do Instagram: materiais originais (fora do git).
